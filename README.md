
# League of Legends Matchmaking Analyzer

## Project Goal
A Java program that helps League of Legends players analyze their matchmaking experiences by tracking match results, opponent ranks, and LP changes.

## MVP Features
- Manually enter match results and opponent ranks
- Record LP gains and losses
- Save and load match history using CSV files
- Calculate overall win rates and average LP changes
- Analyze win rates against different opponent ranks
- Display statistics through a command-line interface

## Future Plans
- Riot Games API integration
- Graphs showing win rates and LP trends
- Champion-specific statistics and KDA
- Solo/Duo and Flex Queue comparisons

## Tech Stack
- Language: Java
- Libraries: Java Standard Library
- Storage: CSV files
- Development Environment: VS Code
- Interface: Command Line
- Data Source: Manual user input

- src/ - Java source code
